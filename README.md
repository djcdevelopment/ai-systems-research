# AI Systems Research

A structured research archive for AI system architecture, experiments, observations, and synthesis.

## Layout

- esearch/observations/ — concrete things learned while building
- esearch/experiments/ — intentional design tests
- esearch/questions/ — open lines of inquiry
- esearch/snapshots/ — meaningful system states
- esearch/synthesis/ — exploratory synthesis across artifacts
- rtifacts/ — generated support material

## First Steps

1. Add RESEARCH_CONTRACT.md
2. Add SYSTEM_INDEX.md
3. Create your first observation, experiment, snapshot, and question
