# Complexity Inflection Points

## Inflection Point

Context switching between AI sessions caused repeated rediscovery of repository structure.

### Trigger Signals

- returning to work without remembering earlier reasoning
- scanning repo to rediscover contracts
- repeated AI orientation prompts

### Tradeoffs

Option A: richer documentation everywhere  
Option B: single restart index

Chosen: minimal restart infrastructure.

### Decision

Introduce:

- START_HERE.md
- SESSION_LOG.jsonl
- reasoning graphs

Minimal infrastructure, maximum restart clarity.
