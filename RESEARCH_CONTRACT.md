# Research Contract

## Purpose

This repo stores structured research artifacts for AI system architecture, implementation lessons, and exploratory synthesis.

## Core Principles

1. Research is artifact-first.
2. Observations should be grounded in evidence.
3. Synthesis is exploratory, not deterministic.
4. Explicit structure beats clever prompting.
5. Claims should be traceable to artifacts.

## Artifact Types

### Observation
- concrete thing learned while building
- should include evidence

### Experiment
- intentional test of a design idea
- should include hypothesis, setup, outcome, interpretation

### Question
- open line of inquiry worth preserving

### Snapshot
- meaningful system state at a moment in time

### Synthesis
- pattern-finding across artifacts

## Done Criteria for Article-Ready Topic

- 3+ observations
- 1+ experiment
- 1+ snapshot
- 1+ meaningful question
- enough evidence to support 2–3 candidate claims
